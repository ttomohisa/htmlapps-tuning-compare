# 音律聞き比べ / Tuning Compare

平均律・純正律・カスタム音律をA/Bで聞き比べ、簡易譜面・WAV・プロジェクトJSONまでブラウザ内で扱えるBrowser Kitty向けアプリです。

**v0.9.0 は Release Candidate です。**

## v0.9.0で見直したところ

### A/B 音律比較

再生操作を次の3つに整理しました。

- **Aを再生**
- **Bを再生**
- **停止**

再生中の側はボタン自体が選択状態になり、A / B表示でも確認できます。

基準音・基準周波数・純正律の主音は、現在選んでいる音律に関係なく変更できます。

また、v0.8.0で複数要素のイベント登録に単一要素用の `$` を使っていた箇所を修正しました。この実行時エラーにより、A/Bの選択肢生成や譜面再生ボタンの初期化が途中で止まる問題がありました。

### 簡易譜面

譜面を **4小節** に拡張しました。

入力位置は選択中の音価に合わせてスナップします。

4/4なら、

- 全音符: 1位置
- 2分音符: 2位置
- 4分音符: 4位置
- 8分音符: 8位置

を1小節内の基本位置として使います。

さらに、

- 音符をドラッグして音高・開始位置を変更
- 和音を共有ステムで表示
- 音符周辺の大きすぎる透明選択領域を廃止
- 近くの高さにも音符を追加しやすく改善
- 休符で既存音符を無言上書きしない
- 音符で既存休符を無言上書きしない
- 4小節に合わせて再生カーソルを更新

を入れています。

## 主な機能

- 12平均律
- 5-limit純正律
- カスタム音律のHz / 比率 / cent編集
- A/B周波数・cent差比較
- 聞きどころ表示
- 4小節の簡易譜面
- サンプル譜面
- A / Bでの譜面再生
- WAV出力
- プロジェクトJSON
- Undo / Redo
- 日本語 / 英語
- 端末内自動保存
- 実行時の外部通信なし

## プライバシー

譜面、音律、比較計算、JSON、WAV生成はブラウザ内で処理します。入力内容や生成音声を外部へ送信しません。
